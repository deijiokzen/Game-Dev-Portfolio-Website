Gimmicks

There's an innumerable amount of gimmicks I've implemented, here's a look at some of them.

Reflection Bullet

The reflection gun allows you to point a guide, on the trajectory of which you can shoot a bullet that has the ability to reflect. Extensive use of Unity Engine's raycasting.

Non-Euclidean Gateways

Non-Euclidean geometry can be used to create game worlds that are significantly different from the real world, and can allow for gameplay elements that would not be possible in a Euclidean game world. For example, a game set in a world with hyperbolic geometry might allow the player to walk on walls or ceilings, or might feature objects that behave in unexpected ways due to the non-Euclidean nature of the game world.

Perception-Based-Scalable Cube

The cube retains the size you view it in as you pick it up, for example if you stand further from an object, it appears small, picking it up from this distance makes it small in actuality in the game, and vice-versa.

Teleportation Points

Teleportation points allow you to teleport on their location upon being hidden, they retain their size if you draw close or further than them, works on the same logic as the perception-based-scalable cube.

Cube Actualizer Wall

The digit on the cube actualizer wall represents the max number of cubes that can form after a bullet collides with the cube actualizer wall and hits something, if max number exceeds the first cube gets destroyed and replaced by the new cube.

Trailer Gimmicks

Gimmicks

A Sokoban-inspired puzzle game built around a dual-mode shooting mechanic. Below is a breakdown of every tech system explored during development.

Tech#01 — Fundamentals of Sokoban

A block must go on a button to open a door; sometimes multiple different buttons open a door. Simply shooting a block allows it to be pushed onto a button.

Tech#02 — Pushing + Duplication

Two switchable fire modes: Mode 1 interacts with an object (pushing a block); Mode 2 duplicates it into 4 copies. Re-interacting or re-duplicating a duplicate makes it the new parent and destroys the old copies. A count on each block tracks duplication depth — it rises on duplication and falls on interaction.

Tech#03 — Charged Interactions

Holding the shoot button charges your attack, enabling duplication over longer distances or pushing a block across multiple tiles — while only incrementing or decrementing the count once.

Tech#04 — Creating & Destroying Maps

Certain blocks can either create tilemaps or destroy them, rendering areas impassable or unsolvable. Both creation and destruction variants exist, each altering the layout mid-puzzle.

Tech#05 — Black Holes / Grapple Points

Shooting a black hole pulls you toward it; stepping on one pushes you away. The opposing forces create positioning puzzles around movement control.

Tech#06 — Switchable Objects

The switchable 'eyeball' mechanic is an object that can be swapped with any other object. It can only be moved through duplication, or by moving another object a specific distance and switching it out for the eyeball.

Tech#07 — Map Movement

Interacting with a map mover token slides specific map tiles toward you in that direction. The number of times a token can be moved is limited — only through duplication can that count be incremented.
